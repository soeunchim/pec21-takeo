## ២. របៀបដំណើរការលើម៉ាស៊ីនផ្ទាល់ខ្លួន (Local Run)

ប្រព័ន្ធនេះដំណើរការលើ **Port 3027** ដើម្បីកុំឱ្យជាន់គ្នាជាមួយកម្មវិធីមុន (ក.ច.ប) ដែលដំណើរការលើ Port 3000៖

១. ចូលទៅកាន់ Folder គម្រោង៖ `D:\I. ការងារបោះឆ្នោត\កម្មវិធីបូកស្រង់ពិន្ទុនៃការប្រឡង គ.ក.ប\pec21_kkb_web`
២. ចុច Double-click លើឯកសារ **`Start_KKB_2027.bat`** (ឬបើក Terminal វាយ `node server.js`)

## ៣. របៀបតភ្ជាប់ជាមួយ Google Sheets (Cloud Storage)

១. បង្កើត Google Sheet ថ្មីមួយនៅក្នុង Google Drive
២. ចូលទៅ **Extensions (ផ្នែកបន្ថែម) -> Apps Script**
៣. Copy កូដទាំងអស់ពីឯកសារ `google-apps-script.gs` ដាក់ចូល រួចចុច Save
៤. ចុច **Deploy -> New deployment**:
   * ប្រភេទ: **Web app**
   * Execute as: **Me**
   * Who has access: **Anyone**
៥. ចុច **Deploy** ហើយ Copy យក **Web app URL**
៦. ចូលទៅកាន់ប្រព័ន្ធ Web App ត្រង់ផ្ទាំង **"ការកំណត់ & Cloud (Settings)"** ហើយបិទភ្ជាប់ (Paste) URL នោះចូល រួចចុច **រក្សាទុកការកំណត់**។ ប្រព័ន្ធនឹងធ្វើសមកាលកម្មទិន្នន័យទ្វេទិសរវាង Web App និង Google Sheets ដោយស្វ័យប្រវត្តិ!

## ៤. របៀប Deploy លើ Render.com

១. បង្កើត GitHub Repository ថ្មីមួយ រួច Push កូដទាំងអស់ក្នុង Folder នេះឡើង GitHub
២. ចូលទៅកាន់ [Render.com](https://render.com) -> ចុច **New Web Service**
៣. ជ្រើសរើស Repository ដែលបាន Push នោះ
៤. កំណត់ Settings:
   * **Environment**: `Node`
   * **Build Command**: (ទុកទំនេរ ឬ `npm install`)
   * **Start Command**: `node server.js`
   * **Environment Variables**:
     - `GOOGLE_SHEET_URL`: [បិទភ្ជាប់ Google Apps Script Web App URL របស់អ្នក]
៥. ចុច **Create Web Service**។ Render នឹង Deploy ដោយស្វ័យប្រវត្តិតាមរយៈ Free Web Service!
